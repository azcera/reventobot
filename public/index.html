Руководство пользователя

Выбери канал, введи текст и открой Preview. Публикация создаёт сообщение от имени бота. Загрузка контейнера по ссылке позволяет сохранить оригинал или отправить копию. Справка по разметке находится внутри конструктора.

Собирай сообщения, выбирай канал и публикуй от имени бота. Сложные сообщения команд открывай во вкладке «Сообщения в Discord».

Руководство пользователя

Выбери раздел, измени нужные поля и нажми «Сохранить шаблон». Кнопки над текстом вставляют Markdown; Edit и Preview переключают редактирование и просмотр. Для общего вида нажми Preview над формой. Сохраняй переменные в фигурных скобках: бот заменяет их при отправке. Подписи и адреса служебных кнопок редактируются отдельно. Разделители (***, ___, ---), <img src="https://…" /> и <section buttonLabel="Открыть" buttonLink="https://…">Текст</section> размещай на отдельных строках в тексте контейнера. Внутри готовых секций Discord доступно только форматирование текста. Восстановление исходного шаблона сбрасывает весь выбранный раздел. Привязанные постоянные сообщения обновляются при сохранении; остальные шаблоны — при следующей отправке. Для привязки укажи ссылку на сообщение этого бота и сохрани её.

Привяжи постоянные сообщения один раз. При сохранении шаблона они обновляются в Discord. Для остальных шаблонов изменения применяются при следующей отправке.

ПРЕДПРОСМОТР ПОЛЕЙ

Приблизительный вид текста. Размещение компонентов определяет бот. Переменные заменены примерными значениями.

Руководство пользователя

Скопируй ссылку на сообщение этого бота в Discord и нажми «Загрузить». Измени доступные тексты, подписи и ссылки кнопок. Preview показывает черновик, «Сохранить в Discord» обновляет оригинал. Служебные кнопки и вложения сохраняются. Новые разделители, изображения и секции можно вставлять только в текст непосредственно внутри контейнера v2; для полного изменения поддерживаемого контейнера используй конструктор. Если сообщение изменилось параллельно, загрузи его заново.

Редактируй публикации этого бота. Рабочие кнопки, вложения и структура сохраняются. Динамические списки каптов и архивов настраиваются через шаблоны.

ПРЕДПРОСМОТР ПОЛЕЙ

Показываются доступные для изменения поля, без вложений и служебных элементов.

Руководство пользователя

Выбери каналы и роли в соответствующих полях. Несколько ролей добавляй из списка; стрелки меняют порядок, удаление убирает роль из настройки. Пустое поле отключает выбор. Нажми «Сохранить настройки», чтобы применить изменения без перезапуска. «Обновить данные» загружает сохранённые значения и сбрасывает черновик.

Настройки сохраняются в базе и применяются без перезапуска. Пустое значение отключает выбор. Порядок нескольких ролей можно менять стрелками.

Последние 100 действий администраторов. Запрос на публикацию записывается до обращения к Discord, успешное выполнение — отдельной строкой.

Руководство пользователя

1. Нажми «Получить предпросмотр», чтобы сверить состав семьи с Discord. 2. Проверь новый ник, выдаваемые и снимаемые роли в карточках. 3. При конфликте подтверди static персонажа; если Tier-ролей несколько, выбери сохраняемую. Исключение отключает синхронизацию участника, возврат включает её, сброс удаляет ручное решение. 4. После исправлений нажми «Обновить данные». 5. Отметь участников или выбери все изменения и нажми «Применить выбранные». Предпросмотр действует 15 минут и используется один раз. «Остановить» прекращает оставшиеся операции; уже выполненные сохраняются. Tier-роли сохраняются, отсутствие в семье само по себе не снимает роли.

Сверь состав семьи и выбери участников для обновления. Tier 1/2/3 сохраняются. Отсутствие в семье не снимает роли.

Привязку по static можно подтвердить или исправить в карточке участника. После решения конфликтов обнови предпросмотр. При остановке уже выполненные изменения сохраняются.
